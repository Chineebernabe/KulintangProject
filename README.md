# Kulintang Dataset

The dataset can be found [here](https://drive.google.com/drive/folders/1yU2DK8LKDBaGuRdgQ42ndkkLwpYU7ePl?usp=sharing).

There are 9 folders containing videos of kulintang players striking all gongs sequentially. Each folder contains videos from a different location and set of kulintangs.

# Notebooks

## Video_Segmentation_Based_On_Audio_Silences
This notebook contains code required for segmenting videos based on silence detection.
## Audio_Extraction_And_Featurization
This notebook contains code required for converting audio segments into features.
## Model_Training_With_Cross_Validation
This notebook contains code required for training the model with cross validation.
